# บอทตรวจข้อความซ้ำ Telegram

บอทตรวจจับข้อความที่ส่งซ้ำในกลุ่ม Telegram เพื่อป้องกันการส่งถอนเงินซ้ำที่ทำให้เสียเงิน
เมื่อมีการส่งข้อความ **เหมือนกันเป๊ะ** ภายในช่วงเวลาที่กำหนด บอทจะตอบเตือนในกลุ่มทันที

---

## สิ่งที่ต้องเตรียม

1. **บัญชี Telegram** — สำหรับสร้างบอทและเพิ่มเข้ากลุ่ม
2. **โทเคนบอท (Bot Token)** — ขอจาก [@BotFather](https://t.me/BotFather) (ฟรี)
3. **บัญชี Railway** — สำหรับรันบอทตลอด 24 ชม. (สมัครที่ [railway.app](https://railway.app))
4. **บัญชี GitHub** — ใช้ push โค้ดขึ้นไปให้ Railway ดึงไป deploy (ฟรี)

---

## ขั้นตอนที่ 1: สร้างบอทกับ BotFather

1. เปิด Telegram แล้วทักหา **@BotFather**
2. พิมพ์ `/newbot` แล้วทำตามขั้นตอน (ตั้งชื่อ + username ที่ลงท้ายด้วย `bot`)
3. BotFather จะส่ง **โทเคน** มาให้ หน้าตาประมาณ `123456789:AAE...` — เก็บไว้ให้ดี
4. **สำคัญมาก:** พิมพ์ `/setprivacy` → เลือกบอทของคุณ → เลือก **Disable**
   (เพื่อให้บอทเห็นข้อความทุกข้อความในกลุ่ม ไม่ใช่แค่ที่พิมพ์ถึงบอท)

---

## ขั้นตอนที่ 2: เพิ่มบอทเข้ากลุ่ม

1. เปิดกลุ่มที่ใช้ส่งถอนเงิน → เพิ่มบอทเป็นสมาชิก
2. ตั้งบอทเป็น **แอดมิน** ของกลุ่ม (ช่วยให้เห็นข้อความครบ และจำเป็นถ้าจะให้ลบข้อความในอนาคต)

---

## ขั้นตอนที่ 3: Deploy ขึ้น Railway

1. Push โฟลเดอร์นี้ขึ้น GitHub (ดูวิธีด้านล่าง)
2. เข้า [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → เลือก repo นี้
3. ไปที่แท็บ **Variables** ของ service แล้วเพิ่ม:
   | ชื่อ | ค่า |
   |------|-----|
   | `BOT_TOKEN` | โทเคนจาก BotFather |
   | `DUP_WINDOW_MINUTES` | `1440` (24 ชม. — ปรับได้) |
4. Railway จะ build และรันให้อัตโนมัติ ดูสถานะได้ที่แท็บ **Deployments / Logs**

> Railway จะรัน `python bot.py` ตาม `Procfile` ให้เอง

### วิธี push ขึ้น GitHub (ครั้งแรก)

```bash
git init
git add .
git commit -m "duplicate message bot"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

---

## การตั้งค่า (Environment Variables)

| ชื่อ | ค่าเริ่มต้น | ความหมาย |
|------|------------|----------|
| `BOT_TOKEN` | (ต้องใส่) | โทเคนบอทจาก BotFather |
| `DUP_WINDOW_MINUTES` | `1440` | ส่งข้อความเดิมภายในกี่นาทีถึงนับว่าซ้ำ |
| `MIN_LENGTH` | `3` | ข้อความสั้นกว่านี้ไม่ตรวจ |
| `WARNING_TEXT` | (มีข้อความเริ่มต้น) | ข้อความเตือน ใช้ `{ago}` แทนเวลาที่ผ่านมา |

---

## ทดลองรันบนเครื่องตัวเองก่อน (ไม่บังคับ)

```bash
pip install -r requirements.txt
copy .env.example .env
# แก้ไฟล์ .env ใส่ BOT_TOKEN
python bot.py
```

---

## คำสั่งในบอท

- `/start` — เช็คว่าบอททำงาน
- `/status` — ดูสถานะและจำนวนข้อความที่จำอยู่

---

## หมายเหตุ

- บอทเก็บประวัติข้อความไว้ใน **หน่วยความจำ** ถ้า Railway restart (เช่นตอน deploy ใหม่)
  ประวัติจะถูกล้าง — ข้อความที่ส่งก่อนหน้าจะเริ่มนับใหม่ ปกติไม่กระทบการใช้งานจริง
- แยกประวัติตามกลุ่ม (แต่ละกลุ่มไม่ปนกัน)
- ตรวจทั้งข้อความปกติและแคปชั่นของรูป/ไฟล์
